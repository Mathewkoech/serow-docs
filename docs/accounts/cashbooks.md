# Cashbooks

## Overview
Cashbooks track all cash and cash-equivalent transactions in your business. Monitor cash movements, reconcile transactions, and manage multiple cash accounts across branches.

## Accessing Cashbooks
1. Click **Accounts** in main navigation
2. Select **Cashbooks** from sidebar

![Cashbooks List]({{ site.baseurl }}/assets/images/accounts/cashbooks-list.png)

## Dashboard Summary

At the top of the page, you'll see key metrics:

- **Total Cashbooks** - Total number of cashbook entries
- **Reconciled** - Transactions that have been reconciled
- **Pending Reconciliation** - Transactions awaiting reconciliation

## List View

The cashbooks list displays all cash transactions with the following columns:

| Column | Description |
|--------|-------------|
| **Account** | Cash account name (e.g., "cash counter 1 - Main Store", "Cash and cash equivalents") |
| **Branch** | Business branch where transaction occurred |
| **Party** | Customer or supplier involved in transaction |
| **Transaction** | Unique transaction reference number |
| **Mode** | Payment mode (Cash, Mpesa, Bank Transfer) |
| **Amount** | Transaction amount in local currency |
| **Date** | Transaction date and time |

## Filtering & Search

### Available Filters

**Top Filter Bar:**
- **Search** - Search across all fields
- **Account** - Filter by cash account
- **Customer** - Filter by customer name
- **Supplier** - Filter by supplier name
- **Date Range** - Filter by transaction date

### Using Filters

1. Click on any dropdown filter
2. Select desired value
3. Results update automatically
4. Clear filters by selecting "All" or clearing the field

## Transaction Types

### Cash Receipts
- Customer payments
- Sale proceeds
- Deposits from bank

### Cash Payments
- Supplier payments
- Expense payments
- Petty cash withdrawals

### Cash and Cash Equivalents
- M-Pesa transactions
- Mobile money
- Digital wallets

## Common Actions

### Viewing Transaction Details
1. Click on any transaction row
2. View full transaction details
3. Check related documents (receipts, invoices)

### Reconciling Transactions
1. Select unreconciled transactions
2. Match with bank statements
3. Mark as reconciled
4. Update status to "Reconciled"

### Exporting Data
1. Apply desired filters
2. Click **Export** button
3. Choose format (Excel, PDF, CSV)
4. Download report

## Pagination

- Navigate between pages using pagination controls at bottom
- Adjust rows per page (25, 50, 100)
- View total entries count
- Jump to specific page number

## Best Practices

### Daily Operations
- Reconcile cashbooks daily
- Match all M-Pesa transactions
- Verify cash counter balances
- Record all cash movements

### Month-End
- Complete all reconciliations
- Generate cashbook reports
- Verify opening/closing balances
- Archive completed transactions

## Tips & Troubleshooting

**Issue: Pending reconciliations increasing**
- Set daily reconciliation schedule
- Review unmatched transactions
- Verify transaction references

**Issue: Duplicate entries**
- Check transaction references
- Review auto-sync settings
- Contact support if needed

**Issue: Balance mismatch**
- Review all unreconciled items
- Check for missed transactions
- Verify opening balances
